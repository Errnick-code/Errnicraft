# Установка сборки

Для установки сборки понадобится Minecraft **26.1.2** и **Fabric Loader 0.20.1**.

## 01 · Подготовка Minecraft

1. Скачай и установи [Fabric Loader 0.20.1](https://fabricmc.net/) для Minecraft 26.1.2.
2. Запусти игру один раз, а затем закрой её. Это нужно, чтобы Minecraft создал необходимые папки.
3. Открой папку `mods` в директории Minecraft.

## 02 · Установка ClientSync

Скачай следующие файлы и помести их в папку `mods`:

| Файл | Скачать |
|:---|:---|
| **ClientSync 1.3.0** | [Скачать](https://github.com/Errnick-code/Errnicraft/raw/refs/heads/main/clientsync-1.3.0%2B1.20-26.2.jar) |
| **Fabric API 0.155.3** | [Скачать](https://github.com/Errnick-code/Errnicraft/raw/refs/heads/main/fabric-api-0.155.3%2B26.1.2.jar) |

> **Важно:** оба файла должны находиться непосредственно в папке `mods`.

## 03 · Установка сборки

1. Запусти Minecraft.
2. В главном меню нажми кнопку **ClientSync** — она находится справа от кнопки «Сетевая игра».
3. Подтверди закрытие игры. После этого откроется установщик ClientSync.
4. Введи адрес для сборки (это не адрес сервера):

   ```text
   modpack.errnicraft.ru
   ```

5. Нажми **«Подключиться»**, а затем **«Установить»**.
6. Дождись окончания установки. Обычно это занимает 2–5 минут.
7. После завершения нажми **«Готово»** и снова запусти Minecraft.

## 04 · Готово!

<sub>✓</sub> Сборка ERRNICRAFT установлена. Теперь можно запускать игру и подключаться к серверу!

Если при установке возникнут проблемы, напиши в [Telegram-чат сообщества](https://t.me/Errnicraft_chat). Там тебе помогут разобраться.
