# Errnicraft

Гайд по установке сборки
Установите Fabric Loader 0.20.1 для Minecraft 26.1.2: https://fabricmc.net/
Запустите игру один раз и закройте её. Это создаст необходимые папки. Затем откройте папку mods в директории вашей версии Minecraft.
Скачайте файлы clientsync-1.3.0+1.20-26.2.jar и fabric-api-0.155.2+26.1.2.jar (они прикреплены ниже) и поместите их в папку mods.
Запустите Minecraft. В главном меню нажмите кнопку ClientSync (она находится справа от кнопки «Сетевая игра»). Подтвердите закрытие игры — автоматически откроется установщик.
Введите адрес:
modpack.errnicraft.ru
Нажмите «Подключиться», затем «Установить».
Дождитесь завершения установки (обычно 2–5 минут). После окончания нажмите «Готово» и снова запустите Minecraft.
✅ Готово! Сборка полностью установлена и готова к игре.
Если во время установки возникнут какие-либо проблемы, обратитесь в поддержку сервера.
